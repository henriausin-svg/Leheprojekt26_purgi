# Veebilehe projekti tutvustus

Projektiks on Tartu tudengitele suunatud informatiivne veebileht, mis tutvustab linnas asuvaid kasulikke ja huvitavaid paiku ning võimaldab neid interaktiivsel kaardil leida. 

Rühma liikmeteks on Henri, Helena ja Karoliina.

Hetkel vastutab veebilehe kirjutamise osas Helena üldise ja pealehe css-ide eest ning pealehe htmli-i eest. Karoliina vastutab info leidmise eest, mida veebilehele panna, ning kohtade htmli-i eest. Henri vastutab kaardi html-i ja css-i eest ning tegeleb JavaScripti elementide loomisega.

Iga rühmaliige vastutab talle tööplaanis määratud ülesannete õigeaegse täitmise eest ning vajadusel suhtleb teiste rühmaliikmetega, et küsida abi või teha koostööd.
